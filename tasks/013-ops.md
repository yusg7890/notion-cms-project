# Task 013: 운영 편의 기능 (선택)

## 목적 및 배경

MVP 배포 완료 후 실제 운영 중 불편한 점을 해결하는 선택적 개선 작업.
북마클릿 없이 웹에서 바로 캐시 재검증을 트리거할 수 있는 관리자 페이지와
Notion Property 정합성 검증 CLI를 우선 구현한다.

## 관련 파일

- `app/admin/page.tsx` — 신규 생성 (관리자 재검증 페이지)
- `scripts/validate-notion.ts` — 신규 생성 (Notion DB 정합성 검증 CLI)
- `components/common/Sidebar.tsx` — 수정 (선택: 관리자 링크 추가)

## 수락 기준

- `/admin` 페이지에서 시크릿 토큰 입력 후 재검증 버튼 클릭 시 `POST /api/revalidate` 호출 → 성공/실패 피드백 표시
- `/admin` 페이지는 `robots: noindex` 적용
- `npx tsx scripts/validate-notion.ts` 실행 시 Notion DB의 필수 Property 누락 항목을 콘솔에 출력
- TypeScript 컴파일 오류 없음

## 구현 단계

- [ ] 1. `/admin` 관리자 재검증 페이지
  - `app/admin/page.tsx` 생성 — Client Component
  - 시크릿 토큰 입력 필드 + "캐시 재검증" 버튼
  - 버튼 클릭 시 `fetch('/api/revalidate?secret=[입력값]', { method: 'POST' })` 호출
  - 성공 시 "재검증 완료" 메시지, 실패(401/500) 시 에러 메시지 표시
  - `export const metadata` — `robots: { index: false, follow: false }` 적용
  - Sidebar에 관리자 링크 추가 여부는 선택 (추가 시 아이콘만, 텍스트 미표시)

- [ ] 2. Notion DB 정합성 검증 CLI
  - `scripts/validate-notion.ts` 생성
  - `@notionhq/client` 사용하여 AI DB + Expert DB 전체 페이지 조회
  - 각 페이지에서 필수 Property(`stock_name`, `ticker`, `opinion`, `currency`, `summary`, `published_at`, `status`) 누락 여부 확인
  - 누락 항목 발견 시 `[페이지 ID] 누락 필드: [필드명]` 형태로 콘솔 출력
  - 정상이면 "모든 리서치 Property 정상" 출력
  - `package.json`에 `"validate:notion": "tsx scripts/validate-notion.ts"` 스크립트 추가

- [ ] 3. (선택) 다크 모드 사용자 설정 유지
  - `next-themes` 설정 확인 — `storageKey` 기본값으로 localStorage 저장 동작 검증
  - 페이지 새로고침 후에도 선택한 테마 유지 여부 확인

## 테스트 체크리스트

- [ ] `/admin` 접속 → 재검증 폼 표시
- [ ] 올바른 시크릿 입력 + 버튼 클릭 → "재검증 완료" 메시지 표시
- [ ] 잘못된 시크릿 입력 + 버튼 클릭 → "인증 실패" 에러 메시지 표시
- [ ] `npm run validate:notion` 실행 → 누락 항목 또는 "모든 리서치 Property 정상" 출력
- [ ] 다크 모드 선택 후 새로고침 → 선택 테마 유지
